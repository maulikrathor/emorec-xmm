# emorec-xmm

Explainable multimodal (text + audio) emotion recognition on the MELD dialogue
dataset: a gated cross-attention fusion model over frozen RoBERTa (text) and
WavLM (audio) encoders, evaluated against unimodal/concat baselines and a
Gemini benchmark, with an integrated-gradients / attention / occlusion
explainability layer.

**Status:** Review-1 sprint, M0 in progress.

## Install

```bash
pip install -e ".[dev]"
```

## Test

```bash
pytest -q
```

## Data pipeline

MELD isn't bundled with the repo. Point the tools at a local copy of the raw
MELD mirror (CSVs + `.mp4` media) via, in priority order: `--meld-root`,
the `MELD_ROOT` environment variable, or `data.meld_root` in
`configs/base.yaml`. The exact mirror layout (which subdirectory holds which
CSV/videos) is discovered at runtime, not assumed.

```bash
# Stage 1+2 only: validate metadata and inventory media, no audio written.
python scripts/inspect_meld.py --meld-root /path/to/MELD.Raw

# Smoke run: a handful of dev utterances, written to dev_smoke.jsonl.
python scripts/prepare_data.py --stage smoke --meld-root /path/to/MELD.Raw

# Full run over one or all splits.
python scripts/prepare_data.py --stage full --split all --meld-root /path/to/MELD.Raw
```

Both scripts read/write only under `artifacts/` (gitignored): extracted WAVs
under `artifacts/wav/`, manifests under `artifacts/manifests/`, and
validation/inventory/exclusion reports under `artifacts/reports/`.

## Current status

The data pipeline (MELD validation, WAV extraction, manifests), the dataset/
collation layer, the frozen text/audio encoders with an on-disk feature
cache, and the training stack (metrics, weighted loss, trainer, the gated
cross-attention fusion model, and the text-only/audio-only/concat baselines)
are implemented and covered by an offline test suite that requires no MELD
data, no GPU, and no real pretrained checkpoints. Statistical extras
(bootstrap confidence intervals, McNemar's test, 3-seed aggregation) and the
explainability/benchmark/serving layers are not yet built — see "Deliberately
not yet implemented" below.

Reproduce, in order (each step reads/writes only under `artifacts/`):

```bash
# 1. Validate MELD metadata/media, then extract WAVs + build manifests.
python scripts/inspect_meld.py --meld-root /path/to/MELD.Raw
python scripts/prepare_data.py --stage full --split all --meld-root /path/to/MELD.Raw

# 2. Build the on-disk audio feature cache (once per encoder checkpoint).
python scripts/build_cache.py --manifest artifacts/manifests/train.jsonl --config configs/base.yaml
python scripts/build_cache.py --manifest artifacts/manifests/dev.jsonl --config configs/base.yaml

# 3. Train a model (B1 text-only shown; swap --config for audio_only.yaml / xattn.yaml).
python scripts/train.py --config configs/text_only.yaml \
    --train-manifest artifacts/manifests/train.jsonl \
    --dev-manifest artifacts/manifests/dev.jsonl \
    --seed 42 --device auto

# 4. Predict and explain one utterance (the live-demo script).
python scripts/demo_predict.py --ckpt artifacts/runs/<run>/best.pt \
    --config configs/text_only.yaml --random
```
